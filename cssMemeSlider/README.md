# cssMemeSlider
cssMemeSlider task for RSShool Summer bootcamp 2026Q2

## Task
CSS Meme Slider implementation

## Changes
- Created responsive slider with 5 Winnie the Pooh memes
- Implemented pure CSS navigation using hidden radio inputs
- Added synchronized text captions for each slide
- Styled navigation dots with hover and active states
- Applied BEM methodology for class naming
- Made slider full-screen with adaptive images
- Added responsive typography using clamp() for fluid font sizes
- Implemented media queries for tablet (768px) and mobile (480px) breakpoints

## Tested Resolutions
**Mobile:**
- 320×568

**Tablet:**
- 768×1024

**Desktop:**
- 1024×720


## How to Test
1. Open the slider in browser
2. Click on navigation dots to switch slides
3. Verify images and text change synchronously
4. Resize browser window to test responsiveness
